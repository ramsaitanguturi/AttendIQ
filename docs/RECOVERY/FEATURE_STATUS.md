# Feature Status Matrix: AttendIQ

**Audit Date:** 2026-11-10
**Classification Scale:**
- **Working and verified**: Verified end-to-end against requirements with no blocking defects.
- **Partially working**: Core flow functions under normal cases, but exhibits non-trivial bugs, missing spec rules, or incomplete integration.
- **Broken**: Fails to compile/run reliably, loses/corrupts data, displays wrong data, or fails core specification.
- **Not implemented**: Specified in documentation (`docs/DOMAIN_RULES.md`, `docs/FEATURES.md`, `docs/MVP_SCOPE.md`) but absent from codebase.
- **Unable to verify**: Runtime behavior on device/OS could not be exercised (no Android emulator/device connected).
